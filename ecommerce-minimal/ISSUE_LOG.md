# 当前问题清单

## 本轮已修复

### 1. 旧库与当前代码不兼容
- 现象：
  - 购物车 500
  - 管理员登录 500
  - 客服咨询 500
- 根因：
  - 当前 MySQL 库明显落后于代码版本
- 处理：
  - 先备份旧库
  - 新增并执行：
    - `migration_20260518_complete.sql`
    - `migration_20260518_seed.sql`
- 复测：
  - 主接口恢复
  - 订单闭环恢复

### 2. 活动通知被鉴权误拦
- 现象：
  - `/api/activity-notices` 返回 401
- 根因：
  - 公共白名单漏了该接口
- 处理：
  - 已加入 `AuthInterceptor` 公共白名单
- 复测：
  - 接口已通过

### 3. 老库迁移后默认管理员权限不足
- 现象：
  - `admin` 迁移后默认只是 `ADMIN`
  - 高权限后台入口无法访问
- 处理：
  - 在补种子脚本里将 `admin` 升为 `SUPER_ADMIN`
- 复测：
  - 高权限后台接口已通过

### 4. Docker 后端镜像构建依赖外网，当前机器复验不稳定
- 现象：
  - 容器构建阶段在 Maven 拉取依赖时握手失败
- 根因：
  - 当前网络环境下，容器内再次联网拉依赖不稳定
- 处理：
  - 后端镜像改为复用已打包好的 `target` 产物
- 复测：
  - 根目录主栈已成功启动
  - `microservices` 栈已成功启动

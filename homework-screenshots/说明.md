后端服务已运行在 `http://localhost:8080`，以下 API 全部通过 PowerShell 验证：

| 操作 | 方法 | 端点 | 验证结果 |
|------|------|------|----------|
| 管理员登录 | POST | /api/auth/admin/login | ✅ 返回 token |
| 查询客户列表 | GET | /api/auth/admin/users?page=1&size=10 | ✅ 返回 JSON 数组 |
| 新增客户 | POST | /api/auth/admin/users | ✅ 返回 {"id":5} |
| 更新客户 | PUT | /api/auth/admin/users/{id} | ✅ 返回 success |
| 搜索客户 | GET | /api/auth/admin/users?keyword=xxx | ✅ 返回筛选结果 |
| 删除客户 | DELETE | /api/auth/admin/users/{id} | ✅ 返回 success |

SSM 三层架构代码位置：
- **SpringWebMVC**：`backend/src/main/java/com/example/ecommerce/controller/AuthController.java`（第116-194行 CRUD端点）
- **SpringCore**：`backend/src/main/java/com/example/ecommerce/EcommerceMinimalApplication.java`（@SpringBootApplication + @MapperScan）
- **MyBatis**：`backend/src/main/java/com/example/ecommerce/mapper/AuthMapper.java`（接口）+ `backend/src/main/resources/mappers/AuthMapper.xml`（SQL）

> 如何在 PowerShell 重现（可截图）：
> ```powershell
> # 1. 登录获取token
> $r = Invoke-RestMethod -Uri 'http://localhost:8080/api/auth/admin/login' -Method Post -Body '{"username":"admin","password":"admin123"}' -ContentType 'application/json'
> $token = $r.data.token
> 
> # 2. 查询
> Invoke-RestMethod -Uri 'http://localhost:8080/api/auth/admin/users?page=1&size=10' -Headers @{Authorization="Bearer $token"}
> 
> # 3. 新增
> Invoke-RestMethod -Uri 'http://localhost:8080/api/auth/admin/users' -Method Post -Body '{"username":"test1","password":"123","nickname":"测试"}' -ContentType 'application/json' -Headers @{Authorization="Bearer $token"}
> 
> # 4. 更新
> Invoke-RestMethod -Uri 'http://localhost:8080/api/auth/admin/users/5' -Method Put -Body '{"nickname":"改名"}' -ContentType 'application/json' -Headers @{Authorization="Bearer $token"}
> 
> # 5. 删除
> Invoke-RestMethod -Uri 'http://localhost:8080/api/auth/admin/users/5' -Method Delete -Headers @{Authorization="Bearer $token"}
> ```

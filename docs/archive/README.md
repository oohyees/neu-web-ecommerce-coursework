# 归档文档

此目录包含历次迭代产生的历史文档，**内容可能已过时，不保证与当前代码一致**。

需要了解项目当前状态，请从 [../README.md](../README.md) 开始。

## 目录

| 目录 | 来源 | 说明 |
|------|------|------|
| `dev-log/` | 原 `docs/dev-log/` | 开发期间的交接笔记、缺口日志、问题追踪、项目状态快照（2026-05 阶段） |
| `frontend-review/` | 原 `docs/frontend-review/` | 早期前端 UI 审查与改进建议，开发前期参考材料 |
| `*.md` | 原 `docs/acceptance/` | 各版本的验收报告、证据清单、演示脚本、微服务验收命令 |
| `old-*.md` | 原 `docs/archive/` | AI 代理配置、数据来源引用、交付清单、报告提纲 |

## 为什么归档

项目历经多轮迭代，这些文档在各自阶段发挥了作用，但包含时间敏感信息（"当前状态"声明、临时修复记录、阶段性验收结论），已不能作为单一真相源。

当前有效的文档在 `docs/` 根目录和 `course/` 目录。

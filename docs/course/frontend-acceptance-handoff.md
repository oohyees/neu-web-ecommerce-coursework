# 前端验收优化交接

更新时间：2026-06-06

## 总目标

所有工作只服务一个目标：最大化《Web开发技术》大作业绩点。老师除最后“拓展创新”可能看代码外，主要通过前端页面验收功能，所以前端展示、交互闭环、页面完整度、响应式、演示数据干净程度优先级最高。

不要为了生产级架构、炫技技术栈、复杂重构浪费时间。后端和微服务只在能支撑前端验收、指导书评分点、截图/报告证据时才值得动。

## 当前项目真实状态

基于源码判断，不基于 README/报告：

- 当前主线前端是 `frontend/shop-web` / `frontend/admin-web` 这套 Vue3 + TypeScript 前端，默认开发代理和最近 git 提交都指向 `http://localhost:18090` Gateway。
- `backend/gateway-service/auth-service/product-service/order-service/admin-service` 是当前主展示架构路径，能证明 Gateway/Nacos/Feign/Docker，也承接当前前端页面验收。
- `backend/legacy-web` 仍是完整单体对照系统，保留 Controller、Service、Mapper、Model、Redis、Mail、WebSocket、Servlet/JSP/Filter/Listener/JDBC 课程证据，用于传统 Java Web 展示和兜底回归。
- 微服务代码多为 Controller + JdbcTemplate，Feign 主要是 `order-service -> product-service`。
- 课程验收策略应是：页面验收优先走当前 Vue 前端 + Gateway；传统 Web 证据再展示 legacy；创新部分展示 Nacos/Gateway/Feign/Docker/Redis 证据。

## 本项目前端待优化点

按验收价值排序：

1. 让隐藏功能显眼
   - 首页第一屏或第一屏下方直接放：秒杀、优惠券、公告、客服/咨询、活动通知。
   - 用户中心首页做功能宫格：订单、地址、收藏、优惠券、评价、反馈、客服、账户安全。
   - 商品详情首屏突出：规格、库存、销量、促销价、收藏、评价入口。

2. 后台统一观感
   - 所有后台页面统一：标题区、搜索区、主操作按钮、表格、分页、空状态。
   - 商品、订单、用户、评价、反馈、咨询、轮播、公告、促销页面风格保持一致。
   - 导入/导出按钮要在后台工具栏显眼出现。

3. 后台移动端兜底
   - 390px 和 768px 下检查后台侧边栏、抽屉菜单、表格横向滚动、筛选栏换行、弹窗/Drawer 宽度。
   - 老师缩窗口时后台不要出现遮挡、按钮挤爆、表格撑破。

4. 订单评价链路
   - 我的订单中已完成订单应有“去评价”。
   - 商品详情评价区要能看到评价内容和图片。
   - 这是商品模块进阶项，前端入口明显比后端实现细节更重要。

5. 后台系统感
   - 如果时间允许，补一个轻量“操作记录/系统状态”页面或卡片。
   - 不需要复杂后端，能显示最近后台操作、待处理反馈、待处理咨询、待退款订单即可。

6. 空状态和脏数据
   - 所有空列表要有专业空状态，不要像没实现。
   - 演示前必须重置数据，避免 QA/test/import/smoke 商品、分类、订单出现在页面。

## 不建议做

- 不优先做 RabbitMQ、OSS、真实支付、AI 客服、搜索引擎、Kubernetes。
- 不大规模重构后端微服务。
- 不为了组件化重写页面。
- 不追求“架构最先进”，只追求老师点页面时最稳、最完整、最好解释。

## 前端检查清单

用户端演示顺序：

1. 首页：轮播、分类、热门、新品、促销、公告/活动入口。
2. 商品列表：搜索、分类筛选、价格/销量/新品排序、分页。
3. 商品详情：图片、名称、价格、库存、规格、详情、评价、收藏、加购。
4. 购物车：数量修改、删除、勾选、全选/反选、小计。
5. 结算：地址、商品清单、优惠券、总价。
6. 支付：模拟支付。
7. 我的订单：状态 Tab、详情、取消、确认收货、退款、物流、评价入口。
8. 用户中心：资料、地址、收藏、优惠券、反馈、客服、账户安全。

后台演示顺序：

1. 登录和退出。
2. Dashboard：用户数、订单数、销售额、今日数据、趋势图、热销排行、订单状态。
3. 商品管理：搜索、筛选、新增、编辑、上下架、库存/价格、上传、导入导出。
4. 分类管理：新增、编辑、删除、排序。
5. 评价管理：查看、删除/处理。
6. 订单管理：搜索、状态筛选、详情、发货、退款、状态修改、导出。
7. 用户管理：搜索、分页、启用/禁用、详情。
8. 内容/系统：轮播、公告、活动通知、反馈、咨询、管理员/权限、个人中心。
9. 响应式：390px 和 768px 用户端 + 后台抽屉菜单。

## 最优下一步

先不要跑大测试。先人工打开当前 Vue 前端源码和页面，做一个最小前端优化批次：

1. 检查首页、商品详情、用户中心、后台 Dashboard 是否把高分点显眼展示。
2. 检查后台所有列表页工具栏和空状态是否统一。
3. 检查 390px/768px 下后台菜单、表格、Drawer。
4. 只做低风险 Vue/CSS 改动。
5. 改完跑：
   - `npm --prefix frontend/shop-web run build`
   - `npm --prefix frontend/admin-web run build`
   - 必要时浏览器人工巡检。

不要在没有明确验收收益时动后端架构。

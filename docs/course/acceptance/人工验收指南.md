# 人工验收指南

本文档严格按《Web开发技术》实验指导书正文逐条拆分。原则是：指导书原文一个点，对应一项人工验收，避免把多个要求合并后漏测。

建议验收时在“验收结果”列手写：通过、部分通过、不通过、未测；如部分通过或不通过，在“问题记录”列写清页面、账号、操作和现象。

## 0. 验收准备

人工验收前先恢复演示数据，避免 smoke 测试生成的 QA 用户、测试订单、导入商品、评价图片影响判断。

scripts/reset_demo_data.sh both

## 9. 促销有效性专项检查

促销数据曾经因为固定结束时间导致重置库后活动过期，所以最终验收前单独检查一次。

```bash
curl http://localhost:18080/api/marketing/promotions
```

通过标准：返回数据中包含 `FLASH_SALE` 和 `PROMOTION`，`endAt` 为 `2026-12-31T23:59:59` 或晚于课程验收日期。
